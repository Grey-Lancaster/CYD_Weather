Install CYD Weather

A weather dashboard for the ESP32 “Cheap Yellow Display” (CYD): forecast, hourly detail, trends, sun & moon and alerts, set up from your phone or computer. Code and docs: GitHub repository.

Release candidate 2.0.0-rc2. This is a test version of the new 2.0 release. The 3.5-inch build (button 4) has not been tried on real hardware yet — if you test it, please tell us how it went in the issues.

Plug the board into your computer with a USB cable and click the button for your board, using Chrome or Edge (a browser with Web Serial; Firefox and Safari can’t do this). If no serial port shows up, install the CH340 USB driver below.

Which button? It depends on the display panel in your board, not on the number of USB ports. Start with button 1. A wrong choice shows a white screen or odd colours; nothing is damaged, just flash another button.

Note: installing from this page replaces everything on the board, including a saved WiFi login and settings, and the first start asks for WiFi again (on the 2.8″ boards it also asks you to touch five crosshairs to calibrate touch). To update a board that already runs 2.0 and keep its settings, use Firmware update on its settings page instead (see the README).

1. CYD — ILI9341 display, normal colours

The standard CYD and many boards with two USB ports. Try this one first.

2. CYD2 — ST7789 display

Boards with two USB ports and an ST7789 display. Choose this if button 1 gives a white screen.

3. CYD2 alternate — ILI9341 display, inverted colours

Choose this if button 1 shows a negative picture (colours inverted).

4. 3.5-inch CYD — ST7796 display, 480×320

Only for the 3.5-inch CYD (for example the ESP32-32E / ESP32-3248S035). The dashboard is shown centred on the larger screen, and the first start asks you to touch four corners to calibrate touch.

After installing

  1. Pick your WiFi network on the screen and type its password.
  2. The screen then shows the board’s IP address and name (for example cyd-weather.local) for 15 seconds. Open that address in a browser to set your location, units and display options. Forgot it? Press the BOOT button on the board to see it again.
  3. Swipe left or right on the screen to change pages.

Do you need CH340 drivers?

If your computer doesn’t see the board when you click an install button, install the CH340 USB-to-serial driver, then unplug and reconnect the board:

  • Windows driver (CH340)
  • Mac driver (CH340)
